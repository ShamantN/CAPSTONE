## 2. Evaluation Arms & Stage Architecture

### Phase 1 Arms (Stage B)
1. **`v2_final`**: The primary full pipeline execution using the selected winning configuration (`C0`, hash `df4a0a2648ac`). Evaluates 3 random seeds per scene across 12 storyboard scenes across $R = 4$ replicates ($12 \times 3 \times 4 = 144$ scene renders).
2. **`v2_final_bon3`**: Deployment-realistic best-of-3 selection across the 3 seeds already rendered by `v2_final`. Requires **zero extra generation**. Winning scene per slot is chosen by deployment-realistic automated gate:
   - Tier 3: Correct person count (YOLO) and all expected faces detected.
   - Tier 2: All faces detected, but extra person detected.
   - Tier 1: Person count matched, but face detector missed a crop.
   - Tier 0: Severe mismatch.
   - Secondary tie-breakers: face sharpness DESC, InsightFace `buffalo_l` similarity DESC, lowest seed ASC.

### Reserved Arms (Stage D — strictly blocked until authorized)
3. **`naive`**: Plain SDXL generation using standard prompt text only (no Regional Couple, no IP-Adapter, no FaceSwap, no FaceDetailer, no WardrobeLock).
4. **`v1`**: Legacy MMCCP v1 pipeline (global IP-Adapter, no regional attention, single anchor).
*Stage D arms are hard-blocked in `eval3/runner.py` and require explicit human input to unlock.*

## 6. Anchor Certification & Separation Gate

Every character anchor synthesized during replicate setup must pass the **4-Point Admission Gate**:
1. **Single Detected Face:** Exactly 1 face found by DeepFace detector.
2. **Face Size:** Face bounding box width $\ge 96$ px.
3. **Sharpness:** Laplacian variance $\ge 60.0$.
4. **No Structural Defects:** Zero melted face or cranial deformation flags.

### Selection Rule
Among certified candidates, select candidate maximizing:
$$\text{Selection Score} = \text{Detector Confidence} \times \text{Face Width (px)}$$
Ties broken to lowest seed. If no candidate certifies, select highest score among uncertified and tag `uncertified_anchor = True`.

### Intra-Replicate Separation
Across all pairwise characters within a replicate, mean 4-judge impostor similarity must satisfy:
$$\text{Similarity}(c_i, c_j) < 0.42$$

## 7. Metrics & Verification Taxonomy

Every evaluation metric is permanently tagged as **OUT-OF-LOOP** or **IN-LOOP**:

### Primary Metrics
- **PM1: Cross-Scene Identity AUC [OUT-OF-LOOP]**
  Evaluated on within-replicate face pairs across distinct scenes using the independent 4-judge DeepFace ensemble (Facenet512, SFace, GhostFaceNet, ArcFace) calibrated via logistic Platt scaling.
- **PM2: Cross-Scene Leave-One-Scene-Out Rank-1 Accuracy [OUT-OF-LOOP]**
  Intention-to-treat denominator: all expected character slots across scenes in the replicate. A probe face in scene $k$ must match its genuine character gallery centroid over all other scenes at Rank 1.
- **PM3: Scene Correctness Rate [OUT-OF-LOOP]**
  Binary scene-level check: all expected characters present (face detector), no extra person (YOLO detector), and left/right spatial order correct.

### Secondary Metrics
- **Judge-Specific AUCs [OUT-OF-LOOP]:** Facenet512, SFace, GhostFaceNet, ArcFace.
- **Biometric Separation [OUT-OF-LOOP]:** $d'$, EER, TAR@FAR=0.05.
- **Face Sharpness [OUT-OF-LOOP]:** Laplacian variance.
- **Extra Person Rate [OUT-OF-LOOP]:** YOLO count $>$ expected count.
- **Face Recall [OUT-OF-LOOP]:** Detected faces / expected face slots.
- **Visual Continuity [IN-LOOP]:** InsightFace `buffalo_l` anchor similarity, Wardrobe CIELAB $\Delta E$, spatial IoU.

## 9. Statistical Analysis Plan

1. **Hierarchical Cluster Bootstrap:**
   - Level 1: Draw $R$ replicates with replacement.
   - Level 2: Within each replicate, draw $N$ scenes with replacement (cluster bootstrap preserving within-scene character dependencies).
   - Resamples: **10,000 bootstrap iterations**.
   - Output: Empirical mean, standard deviation, and 95% Confidence Intervals (2.5th and 97.5th percentiles).
2. **Permitted Verdict Vocabulary:**
   - Reports must state absolute levels (e.g. *"achieved a cross-scene AUC of 0.94 [0.91, 0.97]"*).
   - Under no circumstances may Phase 1 reports state that v2 is "better", "improved", or "outperformed" any other system.
3. **Reference Points:**
   - **PM1 AUC:** Chance Floor = `0.50` | Theoretical Ceiling = `1.00`.
   - **PM2 Rank-1:** Chance Floor = $1 / K$ ($0.20$ for 5-char story) | Theoretical Ceiling = `1.00`.
   - **PM3 Rate:** Chance Floor = `0.00` | Theoretical Ceiling = `1.00`.
